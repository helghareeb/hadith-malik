# موطأ الإمام مالك — hadith-malik

Book site of the hadith project on [helghareeb.github.io](https://helghareeb.github.io/ar/hadith/), served at
https://helghareeb.github.io/hadith-malik/.

The pages are built from the main site's repository ([helghareeb/helghareeb.github.io](https://github.com/helghareeb/helghareeb.github.io))
with `HADITH_BOOK=malik`; this repository holds only the deploy workflow, so each book has its own GitHub Pages space.
Audio is served from Google Drive.
